# Kkd16 Tap

## How do I install these formulae?

`brew install kkd16/tap/<formula>`

Or `brew tap kkd16/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kkd16/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
